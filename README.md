# ManakAI

## AI-Powered Recommendation Engine for Identifying Applicable Indian Standards

**Tagline:** Right Standard. Better Specifications. Smarter Procurement.

ManakAI is an AI-powered system designed to analyze technical procurement specifications and recommend relevant Indian Standards (IS).

## Key Features

- AI-based technical specification analysis
- Intelligent matching with relevant Indian Standards
- Match scores for recommended standards
- Allied standard identification
- Normative standard identification
- Cross-reference detection
- Missing reference detection
- Standard revision and status validation
- Explainable recommendations
- Procurement-focused results dashboard

## System Workflow

Specification Input  
↓  
AI/NLP Analysis  
↓  
Standard Matching  
↓  
Cross-Reference Mapping  
↓  
Version Validation  
↓  
Recommended Standards
